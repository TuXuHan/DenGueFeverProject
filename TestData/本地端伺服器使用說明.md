# 🌐 台南市行政區相似度分析 - 本地端伺服器使用說明

## 🚀 快速啟動

### 方法一：使用啟動腳本（推薦）

#### Mac/Linux 用戶：
```bash
# 在終端中執行
./start_server.sh
```

#### Windows 用戶：
```cmd
# 雙擊執行
start_server.bat
```

### 方法二：手動啟動
```bash
# 在 TestData 目錄中執行
python3 -m http.server 8000
```

## 🌐 訪問網頁

### 主要頁面
- **互動式地圖**: http://localhost:8000/enhanced_interactive_map.html
- **檔案列表**: http://localhost:8000/

### 在瀏覽器中打開
1. 打開任何瀏覽器（Chrome、Firefox、Safari、Edge）
2. 在地址欄輸入：`http://localhost:8000/enhanced_interactive_map.html`
3. 按 Enter 鍵

## 🎯 使用功能

### 1. 點擊地圖
- 直接點擊地圖上的任何行政區
- 右側會彈出該區的詳細相似度分析

### 2. 搜索功能
- 在左側搜索框中輸入區域名稱
- 點擊「搜索」按鈕或按 Enter 鍵

### 3. 查看排名
- **綜合排名**：該區在37個區中的排名
- **綜合相似度前三名**：最相似的三個區
- **空間距離前五名**：地理位置最近的五個區
- **天氣相似度前五名**：天氣數據最相似的五個區

## ⚠️ 重要注意事項

### 1. 保持伺服器運行
- **不要關閉** 啟動伺服器的終端視窗
- 關閉終端會停止伺服器，網頁將無法載入數據

### 2. 網路連接
- 需要網路連接來載入地圖圖層
- 本地數據（JSON、GeoJSON）不需要網路

### 3. 瀏覽器相容性
- 推薦使用現代瀏覽器
- Chrome、Firefox、Safari、Edge 都支援

## 🛑 停止伺服器

### 在終端中按：
- **Mac/Linux**: `Ctrl + C`
- **Windows**: `Ctrl + C`

## 🔧 故障排除

### 問題1：無法訪問網頁
**解決方案：**
- 確認伺服器正在運行
- 檢查地址是否正確：`http://localhost:8000/enhanced_interactive_map.html`
- 確認沒有其他程式佔用8000端口

### 問題2：地圖無法載入
**解決方案：**
- 檢查網路連接
- 確認 `data/district_boundaries.geojson` 檔案存在
- 確認 `complete_rankings_data.json` 檔案存在

### 問題3：數據無法顯示
**解決方案：**
- 重新整理頁面（F5）
- 檢查瀏覽器控制台是否有錯誤訊息
- 確認JSON檔案格式正確

## 📊 檔案結構

```
TestData/
├── enhanced_interactive_map.html    # 主要互動式地圖
├── complete_rankings_data.json      # 排名數據
├── data/
│   └── district_boundaries.geojson  # 地理邊界數據
├── start_server.sh                  # Mac/Linux 啟動腳本
├── start_server.bat                 # Windows 啟動腳本
└── 本地端伺服器使用說明.md          # 本說明文件
```

## 🎉 開始使用

1. **啟動伺服器**：執行 `start_server.sh` 或 `start_server.bat`
2. **打開瀏覽器**：訪問 `http://localhost:8000/enhanced_interactive_map.html`
3. **開始探索**：點擊地圖上的行政區查看相似度分析
