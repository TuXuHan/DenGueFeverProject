# 🔧 空間距離計算修正說明

## ❌ 原始問題

### 1. 坐標系統問題
- **問題**：使用地理坐標系統（經緯度，EPSG:4326）直接計算歐幾里得距離
- **影響**：距離計算不準確，因為經緯度不是平面坐標

### 2. 相似度轉換問題
- **問題**：直接使用距離值作為相似度
- **影響**：距離越小應該相似度越高，但原始計算沒有正確轉換

## ✅ 修正方案

### 1. 坐標系統轉換
```python
# 原始：使用地理坐標系統
gdf = gpd.read_file('data/district_boundaries.geojson')  # EPSG:4326

# 修正：轉換為投影坐標系統
gdf_projected = gdf.to_crs('EPSG:3826')  # TWD97 / TM2 zone 121
```

### 2. 距離轉相似度轉換
```python
# 使用高斯核函數將距離轉換為相似度
def distance_to_similarity(distances, sigma=None):
    if sigma is None:
        sigma = np.std(distances)
    # 高斯核函數：exp(-d^2 / (2*sigma^2))
    similarities = np.exp(-(distances**2) / (2 * sigma**2))
    return similarities
```
