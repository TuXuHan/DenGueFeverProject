# 🧭 村里數據補值實驗報告

## 1️⃣ 實驗概述

**說明：** 針對台南市7個核心行政區共207個村里，利用「基於相似度的KNN補值法」進行時序資料的缺失值補齊，評估該方法的實際表現與參數影響。

### 實驗設計

| 項目    | 說明                    |
| ----- | --------------------- |
| 數據範圍  | 207個村里 × 51週時序資料      |
| 缺失率   | 10%、15%、20%           |
| k值    | 3、5、7                 |
| 相似度組成 | 特徵相似度（50%）＋時序相似度（50%） |
| 評估指標  | RMSE、MAE、R²、MAPE      |

## 3️⃣ 分析與發現

**說明：** 探討不同參數的影響與整體趨勢。

### (1) k值的影響

* k=7在所有缺失率下皆表現最佳
* k值從3→7，RMSE平均下降約5–8%，MAE下降約3–4

### (2) 缺失率的影響

* 缺失率增加會導致RMSE上升約8–10%
* R²在低缺失率下為負值，高缺失率時轉正，顯示模型穩定度提升
* 補值數量與缺失率呈線性增加（約每+5%多400筆）

### (3) 最佳參數組合

* **k=7**、**缺失率10%** → RMSE最低(55.39)，整體表現最佳

## 5️⃣ 技術方法

**說明：** 補值流程與相似度計算細節。

### (1) 相似度計算

* **特徵相似度**：以23個特徵向量計算餘弦相似度
* **時序相似度**：採用DTW（動態時間規整）距離
* **綜合相似度**：兩者平均（各50%權重）

### (2) KNN補值策略

* 依相似度選擇k個最相近村里
* 過濾相似度<0.1的鄰居
* 以相似度作權重進行加權平均補值

### (3) 數據處理

* 所有特徵經Z-score標準化
* 缺失值以隨機masking模擬
* 全部轉換為float格式以支援NaN運算

| 適用範圍  | 缺失率10–20%的監測資料            |
| 改進方向  | 可增加季節性特徵、調整權重比例或導入時序模型    |
| 應用場景  | 登革熱誘卵桶資料補值、數據品質監控、預測模型前處理 |

## 7️⃣ 結論

**說明：** 實驗成效與技術價值。

1. **方法可行**：KNN補值在村里層級登革熱監測數據中表現穩定
2. **最佳參數**：k=7、閾值0.1為最優組合
3. **指標改善**：RMSE與MAE顯著下降，R²逐步轉正
4. **實務價值**：提供完整可用數據集，提升後續預測模型準確度
5. **技術貢獻**：建立了可重現的村里級補值流程與評估框架
