
# 指定七個區域的村里相似度分析報告

## 分析概述
本分析針對台南市7個核心行政區進行相似度分析，包括：中西區, 仁德區, 北區, 南區, 安平區, 東區, 永康區

## 數據基本資訊
- **分析區域數量**: 7個
- **時間範圍**: 2023年1月-12月（週度數據）
- **主要變數**: 確診數、誘卵桶總數、人口數、噴藥次數、氣象數據

## 實務建議

1. **監測策略**: 根據相似度分析結果，對高相似度區域採用相似的監測策略
2. **防控措施**: 分群結果顯示不同區域的時序模式，可制定差異化防控策略
3. **預測模型**: 相似度分析結果可作為預測模型的參考依據
4. **資源配置**: 根據分群結果合理配置監測和防控資源

## 技術細節

- **特徵提取**: 基於ANALYSIS_SUMMARY.md的方法，提取99個時序特徵
- **相似度計算**: 使用餘弦相似度（特徵）和DTW（時序）
- **分群方法**: KMeans + 層次分群
- **標準化**: Z-score標準化
