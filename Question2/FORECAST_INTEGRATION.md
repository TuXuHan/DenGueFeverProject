# 登革熱預測數據整合功能說明

## 📋 功能概述

成功將登革熱預測數據整合到台南市地圖系統中，實現了以下功能：

### ✨ 主要功能

1. **區域列表顯示**
   - 顯示所有 37 個行政區
   - 每個區域顯示預測病例數
   - 根據病例數量顏色標記（綠色、黃色、橙色、紅色）

2. **村里列表顯示**
   - 點擊區域後，切換到該區域的村里列表
   - 村里按預測病例數從多到少排序
   - 顯示排名徽章（前三名特殊顏色）
   - 每個村里顯示預測病例數

3. **返回功能**
   - 村里列表頁面有「返回區域列表」按鈕
   - 點擊返回時自動清除村里地圖圖層
   - 恢復地圖到初始視圖

4. **地圖交互**
   - 點擊地圖上的區域，自動切換到村里列表
   - 同時在地圖上顯示該區域的村里邊界
   - 村里邊界以綠色顯示

### 顏色分級

#### 區域級別
- **紅色** (>100 例): 極高風險
- **橙色** (51-100 例): 高風險
- **黃色** (11-50 例): 中風險
- **淺黃** (1-10 例): 低風險
- **綠色** (0 例): 無風險

#### 村里級別
- **紅色** (>20 例): 極高風險
- **橙色** (11-20 例): 高風險
- **黃色** (6-10 例): 中風險
- **淺黃** (1-5 例): 低風險
- **綠色** (0 例): 無風險

## 🔧 技術實現

### 數據處理流程

```
CSV 原始數據
    ↓
prepare_forecast_data.py
    ↓
forecast_data_processed.json
    ↓
process_map.py
    ↓
map.html (嵌入預測數據)
    ↓
用戶界面
```

### 關鍵文件

1. **data/prepare_forecast_data.py**
   - 讀取 CSV 文件
   - 整合村里 ID 和預測數據
   - 按區域組織數據
   - 對村里按病例數排序

2. **data/forecast_data_processed.json**
   - 處理後的預測數據
   - JSON 格式，前端直接使用

3. **data/process_map.py**
   - 生成地圖 HTML
   - 嵌入預測數據
   - 創建交互功能

4. **template/map.html**
   - 最終生成的地圖文件
   - 包含所有 JavaScript 交互邏輯

### JavaScript 函數

- `showDistrictList()` - 顯示區域列表
- `showVillageList(districtName)` - 顯示指定區域的村里列表
- `showVillagesForDistrict(districtName, map)` - 在地圖上顯示村里邊界

## 🎯 特色功能

### 1. 智能排序
- 村里按病例數自動排序
- 最嚴重的村里排在最前面
- 便於快速識別高風險區域

- 無縫協同操作

### 4. 統計摘要
- 村里列表頁顯示區域統計
- 總病例數
- 村里數量
