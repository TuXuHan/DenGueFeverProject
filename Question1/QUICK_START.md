# 台南登革熱資料預測系統 - 快速啟動

## 🚀 快速啟動

### 1. 安裝依賴
```bash
cd Question1
pip install -r requirements.txt
```

### 2. 啟動系統
```bash
python main.py
```

### 3. 訪問系統
在瀏覽器中打開：http://127.0.0.1:8000

## 📊 系統特色

- ✅ **3252 個登革熱監測點**：涵蓋台南市 10 個行政區
- ✅ **座標轉換**：TWD97 → WGS84 經緯度
- ✅ **互動式地圖**：Leaflet.js + OpenStreetMap
- ✅ **監測點分類**：按區域和類型顯示
- ✅ **響應式設計**：支援各種螢幕尺寸

## 🛠️ 技術架構

- **後端**：FastAPI + Python
- **前端**：Leaflet.js + Bootstrap 5
- **地圖**：OpenStreetMap
- **資料**：JSON 格式，支援 TWD97 座標轉換

## 🔧 座標轉換

如果需要重新轉換座標：
```bash
python convert_coordinates.py
```

## 📱 使用說明

1. **查看監測點**：左側列表顯示所有監測點
2. **點擊標記**：地圖上的標記可點擊查看詳情
3. **區域篩選**：可根據行政區查看監測點
4. **縮放地圖**：使用滑鼠滾輪或 +/- 按鈕

## 🌐 API 端點

- `GET /` - 主頁面
- `GET /api/locations` - 取得所有監測點
- `GET /api/locations/{id}` - 取得特定監測點
- `GET /api/locations/type/{type}` - 根據類型篩選

## 📞 技術支援

如有問題，請檢查：
1. Python 版本 (建議 3.8+)
2. 網路連接（地圖需要載入 OpenStreetMap）
3. 瀏覽器控制台錯誤訊息
